How the Internet Actually Works

The internet can feel almost magical. You type a website address, press enter and a page appears within seconds. Behind that simple action is a huge system involving DNS, servers, IP addresses, routers, packets and communication protocols.

What is the internet?

The internet is a global network of interconnected computer networks. It allows computers and other devices to exchange information using standard communication protocols.

There is not one single machine called "the internet". Instead, millions of networks, servers, routers, data centers and connected devices work together.

What happens when you open a website?

Suppose you type a website address into your browser. Several steps begin almost immediately.

  1. The browser interprets the web address.
  2. The domain name is resolved using DNS.
  3. The browser discovers the server's IP address.
  4. A connection is established with the server.
  5. The browser sends an HTTP or HTTPS request.
  6. The server processes the request.
  7. The server sends data back.
  8. The browser converts that data into the webpage you see.

What is DNS?

DNS stands for Domain Name System. It translates human-friendly domain names into IP addresses.

Humans prefer names such as example.com. Computers communicate using network addresses such as IP addresses. DNS connects these two worlds.

Think of DNS like a contacts list.

You remember a person's name instead of their phone number. DNS performs a similar translation for domain names and network addresses.

What is an IP address?

An IP address identifies a device or network interface within an internet protocol network.

IPv4 addresses use 32 bits, while IPv6 was introduced with a much larger address space because the number of connected devices has grown dramatically.

What are packets?

Large amounts of information are generally divided into smaller units called packets before being transmitted across networks.

Packets can travel through multiple networking devices before reaching their destination. The receiving system can then use the information to reconstruct the transmitted data.

What do routers do?

Routers help determine where network traffic should go. They examine network information and forward packets toward their destination.

A packet travelling across the internet may pass through many routers and networks before reaching its destination server.

What is a server?

A server is a computer system or software system that provides services or resources to other systems called clients.

When you request a webpage, the web server receives the request and returns the required files or dynamically generated information.

HTTP and HTTPS

HTTP is a protocol used for communication between web clients and servers.

HTTPS uses HTTP over a secure encrypted connection. This helps protect information exchanged between your browser and the website.

Why is the internet fast?

Modern internet infrastructure contains high-capacity fiber-optic networks, powerful data centers, distributed servers, caching systems and sophisticated routing equipment.

Content delivery networks can also store copies of frequently requested content closer to users, reducing the distance data has to travel.

The internet is a system of systems

The internet works because different networks agree to communicate using common protocols and standards.

No single company owns the entire internet. Different organizations operate networks, data centers, undersea cables, exchange points and other infrastructure that collectively forms the global network.

Key takeaway:

When you open a website, your request travels through a complex chain of DNS systems, networks, routers and servers before the browser turns the returned information into the page you see.
